Zeeshan Hospital — Deployment Guide

Get your healthcare platform live in minutes.

🌐 Option A: Render Recommended

Free 24/7 hosting with automatic HTTPS and CI/CD.

  1. Go to dashboard.render.com
  2. Click "New +" → "Web Service"
  3. Select your zeeshan-hospital repo → "Connect"
  4. Name: zeeshan-hospital
  5. Start Command: cd backend && node server.js
  6. Click "Create Web Service"
  7. Wait ~3 minutes for the green "Live" badge

💻 Option B: Vercel (Static)

Best for the frontend-only version.

  1. Install Vercel CLI: npm i -g vercel
  2. Run: vercel in the project root
  3. Follow the prompts to link and deploy
  4. Your site is live at https://zh-project.vercel.app

🔧 Option C: Firebase (Full Stack)

Deploy with Firebase Hosting + Firestore.

  1. Install Firebase CLI: npm i -g firebase-tools
  2. Login: firebase login
  3. Init: firebase init (select Hosting + Firestore)
  4. Deploy: firebase deploy
  5. Your site is live on https://zeeshan-hospital.web.app
