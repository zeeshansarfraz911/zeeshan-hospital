Deploy Zeeshan Hospital - LIVE

Option A: Render (Recommended - 24/7 free hosting)

  1. Go to dashboard.render.com
  2. Click "New +" → "Web Service"
  3. Select "zeeshan-hospital" repo → "Connect"
  4. Name: zeeshan-hospital
  5. Start Command: cd backend && node server.js
  6. Click "Create Web Service"
  7. Wait 3 min for green "Live" badge

Option B: Local (test only)

  1. Open terminal in the ZH folder
  2. Run: cd backend && node server.js
  3. Open http://localhost:3000
